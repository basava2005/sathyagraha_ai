Create a full-stack responsive web application called “SatyagrahAI”, an AI-powered legal assistance and evidence management platform designed for Indian citizens. The website should empower users facing legal problems by allowing them to describe their issues in natural language, after which the AI analyzes the input, identifies relevant laws from the Indian Constitution, IPC, and CrPC, and provides personalized guidance. The system should generate legally formatted documents summarizing the user’s problem, applicable laws, and recommended actions, which can be downloaded as PDF or DOCX files. Users must be able to upload FIR copies (PDF or image) for OCR-based extraction using Tesseract, allowing the system to identify key details such as complainant, accused, and offense information. Additionally, the platform should enable users to upload digital evidence (photos, videos, or documents), which are cryptographically hashed and stored securely with timestamps on a blockchain network like Ethereum testnet or Hyperledger, while the actual files are stored off-chain for privacy. The user interface, built in React.js with Tailwind CSS, should feature pages for login/signup, problem analysis, document generation, FIR analysis, evidence management, legal guidance, and an expert review dashboard. The backend should be developed using FastAPI or Django REST Framework, connected to a PostgreSQL database for storing user data, problems, legal metadata, and blockchain proofs. The AI/NLP functionality should leverage Hugging Face Transformers or spaCy for text analysis and legal mapping, while JWT/OAuth2 ensures secure authentication and TLS/SSL encryption protects data transmission. Include APIs for problem analysis, document generation, FIR uploads, evidence verification, and expert reviews. The system architecture should follow a modular, microservices-based approach, with asynchronous processing for OCR and blockchain operations. The final deliverable must include the complete source code (frontend and backend), database schema, AI model stubs, blockchain integration script, and Docker configuration for deployment. The design should follow a clean, professional theme inspired by government service portals, support multilingual content for accessibility, and guide users step by step through the legal help process—from problem entry to evidence submission and expert validation.
